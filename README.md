# Cognifyz Data Analysis Internship Project

This project was completed as part of my Data Analysis Internship at Cognifyz Technologies.

## Project Overview
In this project, I analyzed a restaurant dataset to find useful insights such as:
- Top cuisines in the dataset
- City-wise restaurant analysis
- Price range distribution
- Online delivery analysis
- Restaurant ratings analysis

## Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
Restaurant dataset used for analysis.

## Project Files
- analysis.ipynb – Data analysis notebook
- dataset.csv – Dataset used for analysis
